A personal study planner and psychiatry knowledge workspace for WordPress.

== Description ==

The plugin provides a 24-week study planner, editable rotation details, a psychiatry knowledge map, disorder and medication records, de-identified clinical learning cases, flashcards, article tracking, personal pearls, and a medical-reference search launcher.

Workspace data is stored in WordPress user meta for the logged-in account. Use the same WordPress account on multiple devices to access the same workspace.

== Installation ==

1. Upload the plugin ZIP via Plugins > Add New Plugin > Upload Plugin, or copy this folder to `wp-content/plugins/psychiatry-study-planner/`.
2. Activate the plugin.
3. Add `[psychiatry_study_planner]` to a WordPress page.
4. Log in to WordPress to use the planner.

== Privacy and safety ==

Do not enter patient-identifying information or protected health information. Use de-identified educational notes only. External search providers receive the terms submitted to them. The planner and its differential-diagnosis tools are not substitutes for clinical judgment, current authoritative references, local policies, or supervision.
