# Security Policy

## Supported version

Security reports should identify the affected plugin version. The latest published release is the preferred version to test.

## Reporting a vulnerability

Please do not post sensitive, exploitable details in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub profile or repository page. Include:

- The affected version and WordPress/PHP versions.
- A concise description of the impact.
- Reproduction steps that do not expose real user or patient data.

Do not include patient records, credentials, session cookies, or production database dumps.

## Deployment caution

This project has not undergone an independent security audit. Keep WordPress and PHP updated, use strong account credentials, maintain backups, and test upgrades on a staging site where possible. Do not store identifiable patient information in this planner.
