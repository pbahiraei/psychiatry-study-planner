# Changelog

Notable changes to this project are documented here.

## 1.4.4

- Added a dashboard launcher for searching external medical references.
- Direct query URLs are used for Google, Google Scholar, and the configured Medscape reference-search route.
- Updated the Medscape search target to pass the query to its reference search route.
- Simplified the external resource choices.

## 1.4.2

- Added editable current Rotation details.
- Added the Psychiatry Knowledge Map and editable disorder profiles.
- Added medication knowledge records, de-identified case records, personal pearls, and article/evidence tracking.
- Added flashcards with simple spaced-review intervals.
- Added a differential-diagnosis learning aid and global search across saved knowledge.
- Added compact mobile bottom navigation and a categorized More panel.

## 1.3.0

- Preserved the login-based WordPress workspace and REST API persistence.
- Added study-plan editing, weekly tasks, and mobile navigation improvements.

> This changelog summarizes major user-facing changes. It is not a complete commit-by-commit history.
